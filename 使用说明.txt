星源石合成器 v2.0 · 使用方法

在线地址：
https://hyulee-newbee123.github.io/star-stone/

本机使用：
1. 解压到任意文件夹
2. 双击「打开模拟器.bat」，或用 Chrome / Edge 打开 index.html
3. 点一下页面后才会播放音效和背景音乐

流程：打造胚子 → 背包选石 → 合成 / 洗练 / 锤炼。星尘罐单独一页，不进背包。
电脑从左侧菜单换页；手机点左上角「菜单」随时开关。顶栏可清空背包与统计，不清星尘罐。

词条数值、抗魔、槽位、洗练 / 鉴定 / 合成 / 锤炼概率和成本都在 js\affix-config.js。改完保存后刷新即可。

不需要安装。如果用 VS Code 的 Code Runner 打开 HTML 会报错，请改用上面的方式。
