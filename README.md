# 星源工坊 · 星源石模拟合成器 v2.3

地下城与勇士星源石的网页模拟器：打造胚子、合成、洗练、锤炼、星尘罐、玉玺演算。  
**非官方、公益开源、仅供娱乐。**

## 在线地址

https://hyulee-newbee123.github.io/star-stone/

手机或电脑浏览器打开即可。第一次可能稍慢（含背景音乐）。点一下页面后才会出声。

若 GitHub Pages 打不开，可换网络，或下载本仓库后双击 `打开模拟器.bat`。

## 怎么玩

1. **打造**：做胚子或批量生成，石头进入背包  
2. **合成**：点祭坛槽位从背包选目标石 / 材料石  
3. **洗练 / 锤炼**：先在背包里设目标，再来这两页  
4. **星尘罐**：单开 / 10 连 / 100 连 / 一直开到锤炼之刃；只在本页统计  
5. **演算**：看技攻分布；AI 评测按目标颗数给最佳方案并和直购对照  
6. 顶栏「清空」会清背包和统计，不清星尘罐  

电脑从左侧菜单换页；手机点左上角「菜单」随时开关。

合成按官方权重**不放回**抽取。3 史诗技攻 + 3 史诗技攻最少 2 技攻。
